# RWU System on Chip Course Project

Shared workspace for HDL design, simulation, testing, and documentation.

## Getting started

1. Accept your GitHub collaborator invitation.
2. Clone the repository:
   ```bash
   git clone https://github.com/Yogeswara-Reddy/rwu-soc-course-project.git
   ```
3. Create a branch for your work, then commit and push your changes.
4. Open a pull request when your changes are ready for the team to review.

Commit source files, testbenches, constraints, and documentation.
Keep generated Vivado outputs and simulation waveforms out of Git.
